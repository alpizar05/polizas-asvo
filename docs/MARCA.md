# Tema Bosque Húmedo

Referencia: Lineamientos de Marca Prueba 1.pdf, páginas 4 y 5.

Paleta digital: musgo #658048, bosque #132B00, hoja #1d741b, fondo #eefddf y amarillo #ebe544. Texto secundario #36502b como adaptación de interfaz para mantener legibilidad. Tarjetas blancas y colores semánticos de rechazo/error conservados.

El tema se aplica en app/styles.css a formulario, panel, acceso, consulta y reemplazo. Amarillo con texto oscuro para acciones principales; nunca texto amarillo sobre blanco. Se conservan tipografías, tamaños relativos, foco, controles y subgrid existentes. No se incorporan fuentes externas ni se modifica el logo.

Verificación visual: portada de escritorio y móvil de 390 px, sin desbordamiento horizontal en móvil. No se realizó revisión visual del panel autenticado.

## Tema actual: Colores ASVO
Variante basada en la paleta principal de la página 1: #658048, #ebe544, #6f716d, #fefefe y #080907. Sustituye visualmente Bosque Húmedo mediante el último bloque CSS. Verde musgo en acentos y titular grande; negro y gris oscuro para lectura; amarillo en llamadas a la acción. Los fondos gris-verde claros son adaptaciones de interfaz. Los colores de error se conservan. El bloque anterior de Bosque Húmedo permanece como base para facilitar la comparación.
